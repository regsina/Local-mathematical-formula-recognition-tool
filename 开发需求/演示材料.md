# 演示材料：核心流程演示视频脚本与介绍文档

## 一、介绍文档（项目 README 摘要）

**本地数学公式识别工具**：面向学习与科研的轻量级桌面应用，将数学公式从图像高效转为可编辑 LaTeX，并接入 WPS 写作流程。核心特性：

- **完全离线**：本地 GPU 推理（PaddleOCR-VL-0.9B），数据不出本机，符合隐私与内网使用场景。
- **多种输入**：截图框选、图片导入（点击/拖拽/Ctrl+V 粘贴）、鼠标手写。
- **可靠输出**：真实验收集（30 张真实截图）端到端可用率 93%~97%；LaTeX 源码可编辑、预览、复制。
- **WPS 兼容**：实测 WPS 文字/演示粘贴 LaTeX 转公式对象。
- **历史与校对**：本地历史自动保存、损坏隔离、继续编辑、单条删除。

## 二、演示视频脚本（约 90~120 秒）

### 镜头 1：引入（10s）
- 画面：论文/教材中的复杂公式截图。
- 旁白："论文里的公式想放进自己的文档，手动输入太麻烦？"

### 镜头 2：启动与界面（10s）
- 画面：双击启动应用，默认落在"图片导入"页（大虚线上传区）。
- 旁白："这是一个完全离线运行的本地公式识别工具。"

### 镜头 3：图片导入识别（20s）
- 操作：拖入一张公式截图 → 点击"提交识别" → 显示识别中 → 展示 LaTeX 源码与预览。
- 旁白："拖入图片，一键识别为可编辑的 LaTeX 源码。"

### 镜头 4：Ctrl+V 粘贴（15s）
- 操作：用系统截图工具截一个公式 → 在应用按 Ctrl+V → 提交识别。
- 旁白："也支持直接粘贴剪贴板里的截图。"

### 镜头 5：截图框选（15s）
- 操作：切到"截图识别" → 窗口完全隐藏 → 框选公式 → 自动识别。
- 旁白："框选即识别，窗口自动隐藏不遮挡。"

### 镜头 6：编辑、预览与复制（20s）
- 操作：在源码区微调一个符号 → 预览自动刷新 → 点击"复制当前源码"。
- 旁白："识别结果可以编辑校对，预览实时刷新。"

### 镜头 7：WPS 落地（20s）
- 操作：打开 WPS 文字 → 插入公式 → 粘贴 LaTeX → 显示为公式对象。
- 旁白："复制到 WPS，公式即刻可用。"

### 镜头 8：历史与隐私（10s）
- 画面：历史记录页（多条记录、占用空间显示）。
- 旁白："全部数据保存在本机，离线可用，隐私无忧。"

## 三、演示注意事项

- 首次启动模型加载约 20~40 秒，建议提前启动应用后再开始录制，避免等待镜头过长。
- 准备 3~5 张覆盖分式、根式、求和、矩阵的清晰公式截图作为演示素材。
- 可补一个手写公式镜头，但需注明"手写为限制项，建议工整书写"。
- 结尾可附 GitHub 仓库地址与运行环境要求。
