# 验收集清单

> 依据 PRD 10.1~10.6 验收口径建设。本清单记录样本来源、覆盖范围、判定方式与统计结果。

## 一、印刷公式验收集（tests/eval_real/）

| 项目 | 内容 |
| --- | --- |
| 样本数量 | 30 张真实截图（Snipaste 截取，高等数学教材/网页） |
| 覆盖类型 | 分式、根式、求和/连乘、定积分/重积分、上下标、希腊字母、矩阵与行列式、导数/偏导/梯度、极限、三角恒等式、欧拉公式等 |
| ground truth | vision 模型转写人工核对（`ground_truth.txt`） |
| 判定口径 | PRD 10.2：LaTeX 本地可渲染 + 数学符号/结构/关系与原图一致 + 无需修改即可在 WPS 形成正确公式 |
| 预测明细 | `predictions_unimernet_small.txt`、`predictions_unimernet_base.txt`、`predictions_paddleocr_vl.txt` |
| 比对工具 | `tests/compare_real.py`（规范化预筛 + 逐条判定） |

### 统计结果

| 模型路线 | 端到端直接可用率 |
| --- | --- |
| UniMERNet small | 约 26.7% |
| UniMERNet base | 约 26.7% |
| **PaddleOCR-VL（x2 预处理）** | **93.3%（28/30）~96.7%（29/30）** |

结论：满足 PRD 印刷公式 ≥90% 目标。

## 二、手写公式验收集（应用画板实际书写）

| 项目 | 内容 |
| --- | --- |
| 样本数量 | 用户实际书写 44 个鼠标手写公式（历史记录 `input_method=鼠标手写`），抽样 20 个核对 |
| 覆盖类型 | 分式、根式、上下标、希腊字母、求和、积分、物理公式等 |
| ground truth | vision 模型转写笔迹（鼠标笔迹辨识度有限，个别样本存疑已标注） |
| 有效核对 | 15 个 |

### 统计结果

| 指标 | 结果 |
| --- | --- |
| 手写可用率 | 约 66.7%（10/15 正确） |
| 目标 | ≥80%（O01 建议值） |
| 结论 | **未达建议值，列为限制项**：交付说明标注"建议工整书写、复杂笔迹需校对" |

## 四、性能计时样本（PRD 10.6）

| 项目 | 口径 |
| --- | --- |
| 计时终点 | 源码与首次预览均显示；渲染失败样例以失败提示显示为终点并单独标注 |
| 样本 | 与验收集共用真实截图（30 张） |
| 实测 | PaddleOCR-VL + x2 预处理 avg 1.47s（5060），满足约 5 秒目标；首轮 CUDA 预热单独计时 |

## 五、使用与复现

```cmd
REM 生成合成样例（仅用于流程自测，不作为质量验收依据）
.venv\Scripts\python.exe tests\gen_eval_set.py

REM 真实验收集评估（需模型就位）
.venv\Scripts\python.exe tests\eval_real.py unimernet_base
.venv\Scripts\python.exe tests\eval_paddle.py

REM 规范化比对
.venv\Scripts\python.exe tests\compare_real.py
```

注意：合成图（matplotlib mathtext 生成）与真实截图分布差异大，**合成图结果不作为模型质量判定依据**（见 G1 记录第二轮论证）。
