# 运行说明与 WPS 操作步骤

## 一、应用简介

本地数学公式识别工具：将单个数学公式的截图、图片或鼠标手写笔迹，在本机识别为可编辑 LaTeX 源码，支持校对、预览、本地历史，并可复制到 WPS 形成公式。**全程离线运行，不上传任何内容。**

## 二、运行环境要求

| 项目 | 要求 |
| --- | --- |
| 操作系统 | Windows 10/11 |
| 显卡 | NVIDIA 显卡（已验证 RTX 5060 8GB；其他 N 卡未验证） |
| 显存 | ≥ 4GB 可用显存（模型推理单模型 <1.5GiB） |
| 磁盘 | ≥ 6GB 可用空间（模型约 2GB + 运行库） |
| WPS | 已验证 WPS 文字/演示 12.1.0.29690 |

## 三、启动方式

### 开发环境运行

```cmd
python -m venv .venv
.venv\Scripts\python.exe -m pip install -r requirements.txt
.venv\Scripts\python.exe run.py
```

### 打包版运行（G3 交付）

解压后双击 `LocalFormulaRecognition.exe`（详见打包说明）。

首次启动会执行环境检查（系统、Python、显卡驱动、磁盘空间），通过后进入主界面。**模型文件需已就位**（见下节）。

## 四、模型文件准备

默认模型为 **PaddleOCR-VL-0.9B**，存放路径：

```
%APPDATA%\LocalFormulaRecognition\models\paddleocr_vl\
```

该目录需包含以下文件（随包提供或按下载清单获取）：

```
config.json
generation_config.json
configuration_paddleocr_vl.py
modeling_paddleocr_vl.py
image_processing_paddleocr_vl.py
processing_paddleocr_vl.py
preprocessor_config.json
processor_config.json
added_tokens.json
special_tokens_map.json
tokenizer.json
tokenizer.model
tokenizer_config.json
chat_template.jinja
model.safetensors
```

模型未就绪时应用回退为占位识别器（仅演示流程，不代表真实识别能力）。

## 五、核心操作

### 1. 图片导入（默认启动页）

- **点击上传**：点击大虚线区域，选择 PNG/JPG/JPEG 图片。
- **拖拽上传**：直接把图片文件拖入该区域。
- **Ctrl+V 粘贴**：截图工具截屏后，直接按 Ctrl+V 粘贴剪贴板图片（焦点在文本编辑框时为正常文本粘贴）。
- 点击"提交识别"。

### 2. 截图识别

- 点击"开始截图框选"，应用窗口完全隐藏，鼠标框选目标公式区域，松开自动识别。
- Esc 取消截图，不启动识别。
- 建议框选**单个公式区域**；多公式区域不保证自动拆分。

### 3. 鼠标手写

- 切换"鼠标手写"页，用鼠标书写公式，支持画笔/橡皮擦/撤销/清空。
- 空白画板无法提交；**建议工整书写，复杂笔迹需人工校对**（手写识别当前为限制项）。

### 4. 编辑、预览与复制

- 识别成功后显示：原图、LaTeX 源码编辑区、预览区。
- 编辑源码后自动刷新预览并自动保存（停止编辑约 1 秒后）。
- 预览使用 mathtext 语法子集；不支持的首版语法显示"渲染失败"，**源码保留、仍可正常复制到 WPS**。
- 点击"复制当前源码"复制 Unicode LaTeX 纯文本。

## 六、复制到 WPS 的操作步骤（实测通过）

1. 在应用中完成识别并校对源码，点击"复制当前源码"。
2. 打开 **WPS 文字**（或 WPS 演示），定位到需要插入公式的位置。
3. 选择菜单 **插入 → 公式**（或公式编辑器入口），在公式编辑状态下粘贴 LaTeX 文本，WPS 将其转换为公式对象。
4. 若直接粘贴到正文未形成公式对象，请确认处于公式编辑入口内，或按 WPS 当前版本的公式插入路径操作。

> 实测样本：`\frac{x+1}{x-1}`、`\sqrt{(a+b)^3}+a^3+b^2` 均成功转为公式对象（WPS 12.1.0.29690）。

## 七、历史记录与隐私

- 每次识别成功自动建立历史记录，含原图、原始源码、编辑后源码、模型信息、时间戳。
- 历史存放于 `%APPDATA%\LocalFormulaRecognition\history\`，不上传任何目录。
- 支持重新打开继续编辑、单条删除（需确认）；损坏记录自动隔离不阻塞其他记录。
- 应用卸载不删除用户数据，需手动清理该目录。

## 八、已知限制

- 复杂手写笔迹识别率有限（抽样约 66.7%），建议工整书写并校对。
- 多公式自动拆分、整页文档识别、批量处理、PDF 导出不在首版范围。
- 预览为 mathtext 子集，部分合法 LaTeX 无法本地预览（不影响复制与 WPS 使用）。
- 断网场景不影响识别；仅首次准备模型时需联网下载（如未随包提供）。
